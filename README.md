# Heneguya_salminicola_genome
This repository contains the genome of _Henneguya salminicola_ assembled from PacBio reads.<br>
Publication: Hadjez, et al. 2026 DOI: [10.1093/molbev/msag244](https://doi.org/10.1093/molbev/msag244).
<br>
## Genome assembly
**Henneguya_salminicola_NextDenovo_soft_masked_EG6.fasta.gz**  
This zipped folder contains the genome assembled with NextDenovo from the PacBio reads.
<br>

## Genome annotations
**Protein_annotation_HSA_BRAKER3.gtf**: The proteome annotation obtained with Braker3.<br>
**Repeat_annotation_HSA_EarlGrey6.gff**: The repeat annotation obtained with Earlgrey6.
