# Heneguya_salminicola_genome
This repository contains the genome of Henneguya salminicola assembled from PacBio reads.

## Genome assembly

**Henneguya_salminicola_NextDenovo_soft_masked_EG6.fasta.gz**  
This zipped folder contains the genome assembled with NextDenovo from the PacBio reads.


## Genome annotations

The other files are annotation files:
The proteome (Protein_annotation_HSA_BRAKER3_eg4_Hydra.gtf).\
The repeats (Repeat_annotation_EarlGrey6.gff)\.
